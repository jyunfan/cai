# CAI 教學遊戲七種範例

這個資料夾提供六種適合工作坊示範的個人練習模板，並連結第七種「全班搶答」。個人模板把題目放在 `data/` 裡，教師或學生可以先替換 JSON/CSV 題庫，再慢慢練習改遊戲規則。全班搶答位於 `/live-quiz/index.html`，需要網站 API 與共同資料庫，不支援離線使用。

## 開啟方式

因為瀏覽器通常不允許直接用 `file://` 讀取外部 JSON/CSV，建議在這個資料夾執行本機伺服器：

```bash
python3 -m http.server 5175 --bind 127.0.0.1
```

然後開啟：

```text
http://localhost:5175
```

也可以直接打開 `index.html` 後，用右上角「上傳題庫」載入自己的 JSON/CSV。

## 七種玩法

| 類型 | 題庫 | 適合教材 |
|---|---|---|
| 選擇題闖關 | `data/quiz.json` | 概念辨識、閱讀理解、形成性評量 |
| 配對記憶 | `data/memory.json` | 名詞定義、雙語詞彙、人物主張 |
| 排序挑戰 | `data/sorting.csv` | 流程、年代、操作步驟、文本結構 |
| 分類任務 | `data/categorization.csv` | 類型判斷、案例分類、錯誤辨識 |
| 情境判斷 | `data/scenario.json` | 個案、倫理、臨床、管理決策 |
| 選項鑑識 | `data/audit.csv` 或 `data/quiz.json` | 逐一判斷原選擇題所有選項，核對理由與重練錯題 |
| 全班搶答 | `/live-quiz/sample.csv` 或 `data/quiz.json` | 單選題全班同步，老師開題、手機作答，答對依序 +5、+4、+3、+2、+1 |

## 老師既有的選擇題

- 名詞與固定對應適合改作配對，先確認是否為一對一。
- 依相同標準判斷的案例適合分類，須保留足夠情境。
- 排序需有完整先後關係，情境判斷需補分支與後果，不能直接套用任意選擇題。
- 第六種選項鑑識可直接讀取原有 `quiz.json`。CSV 使用 `question,A,B,C,D,answer,explanation`，多選答案以分號分隔，例如 `A;C`。
- 可增加 `feedback_A` 至 `feedback_D` 放每個選項的解析。空白選項欄位會略過，至少需有兩個選項。
- 否定題與最佳答案題需保留題幹原文。「不符合題意」不表示該敘述在任何情境都錯誤。
- 每個選項判斷正確得 100 分，全部判斷後才揭示解析，結束可回顧並重練錯題。文字理由用於課堂討論，不自動評分。

## 給學生的練習順序

1. 先只改 `data/` 題庫，不改程式。
2. 把同一個模板換成自己的科目內容。
3. 修改回饋文字，讓答錯時能知道原因。
4. 調整分數或進度規則。
5. 最後才改畫面樣式與互動方式。

## AI Agent 提示詞

```text
請保留目前遊戲玩法與資料格式，只把題庫改成【課程名稱】的內容。
請產生可以直接貼進對應 JSON/CSV 檔案的題庫。
每一道題目都要包含正確答案與學生看得懂的回饋。
```
