# 全班搶答

第七種遊戲。開啟 `/live-quiz/index.html`，老師選「老師開房」，學生選「學生加入」。

## 課堂流程

1. 老師上傳單選題 JSON 或 CSV，選擇 15、30、60 或 120 秒並建立房間。
2. 分享畫面上的學生連結與 6 碼房號。所有学生先以課堂暱稱加入，最多 100 人。
3. 老師開始第一題，學生點選一次答案。開始後不再接受新學生加入。
4. 倒數結束，或老師按「收題並揭曉」，才顯示正解、解析及本題積分。
5. 第一至第四位答對者得 5、4、3、2 分，第五位以後每位 1 分。答錯、未答、逾時 0 分。
6. 老師控制下一題，結束後可下載累積排行榜 CSV。同分並列。

## 題庫

- CSV 使用 `sample.csv` 欄位：`question,A,B,C,D,answer,explanation`。每題只能有一個正解。
- JSON 沿用個人遊戲的 `quiz.json`，每題 `choices` 須有 2–6 個選項且恰好一個 `correct: true`。
- 1–100 題。多選題會拒絕匯入，請改用第六種「選項鑑識」。
- 題庫與學生暱稱以純文字呈現，不執行 HTML。

## 網路與資料

- 這款需要網站 API 與 D1 資料庫，不能以離線 HTML 或普通靜態檔案伺服器提供同步搶答。
- 正式網站必須允許學生存取；私人網站的網址與房號不會繞過網站存取權限。
- 計分以伺服器在資料庫接受答案的順序為準，網路延遲會影響排名，不宜單獨用作正式評量。
- 每人每題僅接受一次提交。答錯不能改答，重送不重複計分。學生可重整原分頁恢復。
- 分頁只保留加入憑證，分數與房間資料以伺服器資料庫為準。關閉或清除原分頁後可能失去主持權或加入身分，請上課時保留原分頁。
- 房間 24 小時後不可存取，過期資料於下一次建立房間時清除。只用暱稱，勿放真實學號或敏感資料。
- 同一個人用多個分頁與不同暱稱重新加入並非實名防作弊功能；需由教師在等候區確認名單。

## 驗證

`node --test tests/live-quiz.test.mjs` 涵蓋計分、同時提交、重複提交、控制權、逾時、題庫與資料清理。
